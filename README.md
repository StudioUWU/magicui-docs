# MagicUI Unreal Engine documentation

Documentation for the MagicUI Unreal Engine plugin. It intentionally documents the plugin workflow,
Blueprint API, UMG widget, imported web assets, and JavaScript event bridge. It
is focused entirely on the packaged Unreal plugin and its user-facing tools.

## Human Statement

> "The doc content is generated by AI, however a human did go step by step to verify the information" - Dill

## Preview locally

Python 3.10 or newer is recommended.

### Windows PowerShell

```powershell
py -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -m mkdocs serve
```

### macOS or Linux

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m mkdocs serve
```

Open <http://127.0.0.1:8000>. The preview reloads when a Markdown, CSS, or
configuration file changes.

## Validate a production build

```bash
python -m mkdocs build --strict
```

On macOS or Linux, use `python3` or the virtual environment's Python path when
`python` is not available. The generated site is written to `site/` and is not
source material.

## Authoring conventions

- Run `mkdocs build --strict` before publishing.

The published site and repository identity are configured in `mkdocs.yml`.

## Publishing

Pushing to the `main` branch runs the GitHub Pages workflow in
`.github/workflows/deploy-docs.yml`. The workflow validates a strict MkDocs
build and publishes the generated site. GitHub Pages is configured for the
custom domain `magicui.studiouwu.com` through `docs/CNAME`.
